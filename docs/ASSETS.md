# Asset catalog

Every visual/audio asset the mod uses, and whether it's a placeholder to replace.
Update this whenever an asset is added or replaced.

Status: **placeholder** = needs real art, **vanilla** = borrowed from the base game
(fine to keep or replace), **final** = done.
